Physical realizations

  • trapped-ion direct encoding demonstrated

    The fixed Shor block was directly encoded and its prepared logical states were characterized on a trapped-ion processor. This establishes an encoder and fixed-block state preparation, not repeated fault-tolerant syndrome cycles or an increasing-distance memory threshold.

    References: nguyen2021shor

  • trapped-ion coherent-idling memory test demonstrated

    A sign-adjusted distance-three Shor-code sector was implemented and compared under correlated coherent idling. The result is specific to the chosen stabilizer eigenvalues, noise Hamiltonian, and fixed block; it is not a model-independent improvement of the canonical code space.

    References: debroy2021optimizing

  • photonic encoded-state and repeater experiment demonstrated

    A photonic nine-qubit Shor state was prepared, while generalized Shor blocks supplied loss protection inside the larger repeater protocol. State preparation and loss-tolerant repeater behavior are distinct from repeated arbitrary-Pauli correction by this fixed memory block.

    References: zhang2022loss
