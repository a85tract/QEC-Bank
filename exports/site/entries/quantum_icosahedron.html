Five-covered icosahedral stabilizer code

A fixed stabilizer code obtained by winding the icosahedron around an axis through opposite triangular faces. The executable graph uses five sheets and six perimeter inputs separated by successive 300-degree turns; the other vertices are physical outputs. Checks follow the source graph-encoder rule, with every input and pivot retained as inspectable data. Distance five is reported by the primary source and remains claimed here. This T1 entry does not survey decoding, operations, or realizations.
