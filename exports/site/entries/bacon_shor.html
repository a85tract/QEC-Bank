Bacon–Shor code

A rectangular grid code that makes Shor's two repetition protections local by treating nearest-neighbour XX and ZZ parities as gauge generators. These gauge measurements need not commute with one another: only their center fixes the protected subspace. The unconstrained gauge subsystem absorbs local changes of representative, while one row-spanning X string and one column-spanning Z string carry the logical qubit.
