Code distance for an executable, paper-audited triangular patch. The current constructor accepts only 3 and 5; it rejects larger odd distances rather than inferring their incidence from a bulk formula.

Exact finite-patch convention. The supported literal is 'three-color-triangle'; closed, punctured, and other planar boundaries are distinct variants.
