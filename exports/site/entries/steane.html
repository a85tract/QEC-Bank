Steane code

A seven-qubit CSS stabilizer code obtained by using the same binary Hamming parity check for X and Z errors. The Hamming code contains its dual, so the two check families commute; their quotient leaves one logical qubit of distance three. The same six checks are the three colored faces of the smallest triangular 6.6.6 color-code patch.
