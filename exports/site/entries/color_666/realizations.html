Physical realizations

  • trapped-ion seven-qubit triangular block demonstrated

    The smallest triangular member was encoded and used for logical operations. This realizes the Steane/color-code intersection at fixed distance, not growth of the 6.6.6 family.

    References: nigg2014topological

  • trapped-ion fault-tolerant logical processor demonstrated

    Fault-tolerant Clifford primitives on small color-code blocks were combined with logical magic-state preparation and injection. The universal protocol includes the injected resource; it is not a universal transversal gate set of one two-dimensional patch.

    References: postler2022universal

  • reconfigurable neutral-atom logical architecture demonstrated

    Many small color-code blocks were moved and coupled through transversal logical operations inside a larger architecture. The experiment is a multi-block operation result, not an increasing-distance memory test.

    References: bluvstein2024logical

  • superconducting triangular color-code processor demonstrated

    Two finite code sizes were operated with repeated syndrome extraction, hardware-specific decoding, transversal Clifford gates, magic-state injection, and logical teleportation by surgery. Size scaling, gate benchmarks, and surgery are distinct claims with distinct observables.

    References: lacroix2025scaling
