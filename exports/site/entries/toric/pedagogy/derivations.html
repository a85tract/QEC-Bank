Reproduction contract

Run from the repository root:

source .venv/bin/activate
python atlas/toric/pedagogy/reproduce.py
make verify-entry E=atlas/toric

The same computation can be launched from a Python session:

from runpy import run_path

run_path("atlas/toric/pedagogy/reproduce.py", run_name="__main__")

reproduce.py imports the shipped constructor and asserts the parameter refusal boundary, cell counts, check ranks, row weights, CSS commutation, global dependencies, exact small distances, four logical supports, periodic scene contract, endpoint-syndrome walk, exact cyclic-HGP matrix equality, and the two-block transversal-CNOT symplectic action. It exits nonzero on the first disagreement. The entry verifier independently recomputes every claim in instances.yaml.

The provenance split is deliberate:

  • n, k, CSS structure, the committed small distances, logical supports, cyclic-HGP equality, and stacked-block CNOT are machine-verified.
  • The all-L distance lower bound is a worked homological proof backed by the primary Toric literature.
  • Decoder thresholds, proposed Clifford gadgets, and hardware results do not follow from a check matrix. They remain literature claims with their full model or protocol identity written beside them.
