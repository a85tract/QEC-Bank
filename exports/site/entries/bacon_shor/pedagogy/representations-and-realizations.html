Compass Hamiltonian

Assign the pair operators as local Hamiltonian terms. The same vertical-X and horizontal-Z pattern becomes the square quantum compass model. Products along complete lines commute with the Hamiltonian and mirror the center-strip symmetries. This makes the energetic role of gauge degrees of freedom visible.

It does not follow that local pair terms produce a topologically ordered or self-correcting memory. dorier2005compass, bacon2006operator, and sarma2013gauge discuss the interaction/symmetry and autonomous-dynamics questions with their own model assumptions. The static code entry exports no Hamiltonian gap, bath, lifetime, or thermal scaling claim.

Tensor-leg reassignment

cao2022quantumlego obtains a Bacon–Shor description by reorganizing a surface-code tensor network and declaring selected dangling legs logical rather than physical. Operator pushing then exposes the pair-gauge structure.

This is a useful explanation of subsystem bookkeeping: changing which tensor legs count as protected versus disposable can turn a stabilizer presentation into a gauge presentation. It is not an exact operation-tree adapter in this repository. A contraction or leg reassignment can also create a new code whose parameters must be recomputed rather than inherited.

Frustration graph and the free-fermion boundary

Build a graph whose vertices are gauge terms and whose edges connect anticommuting pairs. For the rectangular compass pattern, a vertical X edge is adjacent to each horizontal Z edge sharing exactly one endpoint. The graph is constructor-derivable and exposes the nonabelian measurement conflicts.

chapman2022freefermion uses Bacon–Shor as the obstructed comparison when constructing a related free-fermion subsystem model. The fetched source does not establish that ordinary Bacon–Shor is itself free-fermion solvable. The card therefore labels this view a boundary, not a free-fermion realization.

The static trapped-ion experiment is the direct realization attached to this card. The superconducting result is recorded as descendant evidence because its logical qubit and detectors depend on a schedule absent from the static constructor.

As of the 2026-08-02 realization sweep, no increasing-distance below-threshold Bacon–Shor hardware scaling demonstration was found. That dated negative result does not diminish the demonstrated fixed-block primitive suite; it prevents the two evidence levels from being merged.

Variant invariants

Use the following test before transferring a claim:

  • changing only r and c preserves the rectangular pair-gauge grammar but changes sector distances and gauge count;
  • changing the occupancy matrix creates Bravyi–Bacon–Shor row/column codes and can change protected dimension;
  • promoting a commuting gauge subset changes the stabilizer group and creates a compass-code or Shor gauge fix;
  • adding a time schedule changes the detector graph and logical evolution;
  • changing tensor leg roles supplies a representation map whose exact output still needs parameter verification.

Matching words such as "compass," "Bacon–Shor," or "subsystem" do not prove these objects have interchangeable distances, thresholds, operations, or hardware evidence.
