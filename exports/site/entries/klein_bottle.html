Klein-bottle surface code

A homological CSS code on a square cellulation of the Klein bottle. Qubits occupy edges, vertex boundaries give X checks, and face boundaries give Z checks. One pair of rectangle sides is identified normally while the other is reflected; retaining that orientation-reversing seam is what separates this closed nonorientable family from the toric code.
