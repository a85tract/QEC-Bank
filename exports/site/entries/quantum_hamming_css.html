Binary quantum Hamming CSS code

A binary CSS family whose check block is the parity-check matrix of a classical binary Hamming code. The constructor labels columns by all nonzero r-bit vectors and uses the same block for X and Z checks. This is the CSS family containing the Steane and fifteen-qubit Hamming blocks, not the distinct non-CSS perfect-code family with a similar name.
