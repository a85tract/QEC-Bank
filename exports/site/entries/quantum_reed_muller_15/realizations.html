Physical realizations

  • trapped-ion Reed–Muller-to-Steane switching experiment demonstrated

    A fifteen-qubit logical resource was prepared, switched into a Steane block, and the accepted logical magic state was certified. The result demonstrates preparation and code switching, not increasing-distance Reed–Muller memory scaling.

    References: daguerre2025magic

  • reconfigurable neutral-atom logical architecture demonstrated

    Three-dimensional fifteen-qubit blocks were used as teleportation and arbitrary-angle-synthesis resources inside a larger fault-tolerant architecture that also uses other codes and qubit reuse. This is an operation-level demonstration of the fixed block, not a memory threshold for a Reed–Muller family.

    References: bluvstein2025architecture
