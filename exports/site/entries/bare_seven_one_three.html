Bare seven-qubit code

A fixed non-CSS seven-qubit stabilizer block designed so that selected stabilizer measurements can use bare ancillary qubits without turning each single ancilla fault into an uncorrectable data error under the paper's stated setting. The executable identity is Table I's stabilizer block; it is not the CSS Steane code despite sharing length and distance.
