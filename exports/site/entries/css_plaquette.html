CSS plaquette code

A subsystem code with qubits at periodic cubic-lattice sites: X gauges occupy yz and xz plaquettes, and Z gauges occupy xy and xz plaquettes. The executable stabilizer is the full center of this gauge group. Sheet operators change from stabilizers at even size to bare logicals at odd size. This T1 skeleton ships only L=2 and L=3. Its distance is dressed distance, minimizing over operators that commute with stabilizers but lie outside the gauge group; bare logicals must commute with every gauge. Appendix B equation B4 has a parity-count inconsistency, diagnosed against B1 in the source ledger; no B4 parameter formula is adopted. Decoder, operation, relation and realization facets remain unsurveyed.
