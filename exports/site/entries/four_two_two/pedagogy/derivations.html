Reproduction contract

Run from the repository root:

source .venv/bin/activate
python atlas/four_two_two/pedagogy/reproduce.py
make verify-entry E=atlas/four_two_two

The script imports the shipped constructor. It recomputes CSS ranks and exact distance, enumerates all single-qubit syndromes, verifies the logical symplectic table and codeword eigenvalues, checks the erasure Knill–Laflamme matrices, conjugates the logical basis under physical H, S, and inter-block CNOT, and validates both Scene v2 frames. It exits nonzero at the first disagreement.

The provenance split is deliberate:

  • n, k, d, CSS commutation, syndromes, logical representatives, and Clifford conjugations are machine-verified.
  • The one-erasure interpretation is theorem-backed and then checked on the exported finite code.
  • Distillation performance and hardware outcomes remain claimed by their primary sources. They are not inferred from the static check matrix.
