Quantum Golay code

A fixed binary CSS stabilizer block built from the self-orthogonal subcode of the classical binary Golay code. The same declared binary check space is used in the X and Z sectors, so the executable matrix determines the protected quotient without introducing a spatial lattice. This card denotes the quantum block, not the classical Golay code, a qutrit analogue, or the wider quadratic-residue construction.
